## 오른쪽 패널

| 구역 | 패널 | 역할 |
|------|------|------|
| **씬** | **Properties** | 선택 트랙 — **패턴**(기본) / **속성** 탭 |
| **씬** | **그룹** | Characters 묶음 · 포메이션 · 키프레임 적용 (씬마다 별도) |
| **프로젝트** | **패턴 라이브러리** | 동작 패턴 보관함 · 프리셋 링크 유지 · 어느 씬 트랙에나 적용 |
| **프로젝트** | **위치 프리셋** | 무대 공통 좌표 · ⓘ · 칩 → 미리보기 + 트랙/그룹 시작 위치 |
| **씬** | **조명** | HOUSE/Fixture 라이브 · + 키 (씬마다 별도) |

Properties **패턴** = 선택 **한 트랙**(씬). **패턴 라이브러리** = **여러 패턴**(프로젝트). 둘 다 **위치 프리셋**을 시작·끝에 연결할 수 있습니다.

## 타임라인 — Characters / Stage

| 항목 | 내용 |
|------|------|
| **트랙 추가** | Assets **+** · 같은 이름 반복 시 **2, 3…** 자동 번호 · **시작+퇴장 키**·**등장 클립** 막대 자동 생성 |
| **등장 클립** | 툴바 **Clip** / **Keys** · Clip=막대 표시·클릭 선택(금색)·드래그 이동·오른쪽 핸들=퇴장 시각(앞 키보다 짧게 불가) · Keys=막대 숨김 · **Undo/Redo 시 클립 길이도 키와 동기화** |
| **트랙 이름** | 선택 · **F2** · 우클릭 → 이름 변경… · Properties **이름** · Undo 가능 |
| **트랙 삭제** | 선택 · **Del**(확인, 키 미선택) · 우클릭 → 트랙 삭제 |
| **키** | K · D/Del(키) · 드래그 · **◀ ▶** 또는 **,** / **.** 이전·다음 키 · **M** · 우클릭 **키 이동…** · 우클릭 → **패턴 라이브러리에 저장**(키 2+, 프리셋 링크 포함) |
| **키 작업 대상** | 트랙 미선택 시 — 섹션 필터 → 최근 키 작업 트랙 → 선택 트랙 → 첫 Characters 트랙 |
| **Properties** | **패턴**(기본) · **속성** — 퇴장은 **마지막 키 자동 안 보임** · 패턴/그룹/라이브러리에서 설계 · 선택 키에 **표시 체크 없음**(퇴장 키만 「안 보임 (자동)」 안내) |

| Characters | Stage |
|------------|-------|
| X/Z(Y고정) · Y회전 · 틴트 · Opacity | XYZ · 회전 · 크기 · 색 · Opacity |
| 패턴 — 포메이션 없음 · **AI 패턴** · 프리셋 링크 | 패턴 — 동일 UI · AI 패턴 · 프리셋 링크 |

### 패턴 공통 (Properties · 그룹 · 라이브러리)

| 기능 | 설명 |
|------|------|
| **시작 위치** | 시작 시각 · Opacity · 좌표 · 무대 픽 · 위치 프리셋 칩(다시 열면 선택 유지) |
| **+ 구간** | 이동/대기/퇴장 선택 시 **바로 편집 창** · 퇴장은 「**안 보임**」(자동) 안내만 · **표시** 체크 없음 |
| **중간 삽입 · 순서** | 단계 사이 **+** · 카드 드래그 (뒤 단계 삭제 없음) |
| **키프레임 적용** | compound 키 생성 · 프리셋 **절대 좌표** · 등장 Opacity 페이드 |
| **등장 프리셋** | 시작 Opacity 0이어도 첫 키 visible · 페이드 인 |
| **퇴장** | 트랙 **마지막 키**만 `visible: false` 자동 · Opacity 슬라이더는 페이드아웃용 · 클립 뒤에 키 추가 시 퇴장 키 갱신 |

**AI 패턴** (Properties · 패턴 탭 · **?** 도움말):

| 구분 | 쓰는 말 | 의미 |
|------|---------|------|
| **Duration** | `10초 대기` · `1분 대기` · `3초 이동` | 그 구간 길이 |
| **절대 시각** | `1분까지 대기` | 타임라인 그 시점까지 (이동 3초면 대기 57초) |
| **시작 시각** | `시작 5초` · `1분부터` | startTime |
| **@ 위치** | `@등장` `@중앙` `@퇴장` | 저장위치 연결 · 적용 후에도 링크 유지 |
| **키워드 색** | 이동·대기·퇴장 · `머무르다`→`[대기]` | 키 예정 미리보기 |
| **⏱ 기본** | 이동·대기·퇴장(초) — 대기 기본 **10** | 시간 생략 시 · 「~까지」와 별개 |

예) `@등장에서 @중앙으로 이동, 1분 대기 후 @퇴장으로 퇴장` · `@왼쪽에서 @중앙으로 이동하고 1분까지 대기 후 퇴장`. 시간 생략 시 ⏱ 기본 3초.

- **Undo/Redo**: 타임라인 툴바 · 편집 메뉴 · **Ctrl+Z / Ctrl+Y**
