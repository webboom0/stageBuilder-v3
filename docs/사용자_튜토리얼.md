# StageBuilder v4 — 사용자 튜토리얼

**대상:** 공연·무대 연출 작업자  
**형태:** Markdown → 추후 PDF  
**버전:** v4  
**갱신:** 2026-08-26 (Phase 0·1·2·3 초안)

---

## 이 문서 읽는 법

- 번호 순서대로 따라 하면 됩니다.
- `[그림: …]` 자리는 **스크린샷**을 넣을 위치입니다. PDF로 만들 때 캡처를 붙여 넣으면 됩니다.
- 아직 없는 기능(저장·모션·조명 등)은 메뉴에 보이더라도 **Phase 안내**만 뜨며, 이후 절에서 다룹니다. 타임라인(§2)은 Phase 2부터 사용합니다.

---

## PDF로 바꾸는 방법

1. Word에서 열기 → PDF 저장  
2. `pandoc 사용자_튜토리얼.md -o 사용자_튜토리얼.pdf`  
3. 브라우저/에디터 Markdown PDF 확장

## §0 로컬 실행 (Phase 0)

에디터는 **로컬 서버**와 함께 실행합니다.

### 0-1. 서버 켜기

PowerShell에서:

```powershell
cd StageBuilder_v4\server
npm install
npm run dev
```

정상 기동 후 브라우저에서 확인합니다.

| 주소 | 기대 결과 |
|------|-----------|
| http://localhost:3000/api/health | `{ "status": "ok" }` 형태 |
| http://localhost:3000/stageBuilder/index.html | 에디터 화면 |

[그림: 브라우저에 열린 StageBuilder v4 전체 화면]

### 0-2. 화면 구성 (한눈에)

| 영역 | 역할 |
|------|------|
| 상단 메뉴바 | 파일·편집·씬·추가·**보기**·연출·도움말 + 우측 **그리드** 컨트롤 |
| 왼쪽 | 레일 아이콘 → **무대** 패널 |
| 가운데 | 3D 뷰포트 |
| 오른쪽 | Properties (이후 Phase에서 연결) |
| 하단 플로팅 툴바 | 이동/회전/스케일 · 카메라 시점 · 확대/축소 |
| 좌하단 상태바 | API 연결 · 무대 크기 · 안내 메시지 |

[그림: 메뉴바·왼쪽 무대 패널·뷰포트·하단 툴바 레이아웃]

### 0-3. 상태바 읽기

예:

`API OK (http://localhost:3000) | FBX 0 · Audio 0 | 프로시니엄 16×13.5m (216㎡) | 건물+바닥 연동`

| 표시 | 의미 |
|------|------|
| API OK | 서버 연결 성공 |
| FBX / Audio 숫자 | `server/files/` 목록 개수 (없어도 0이면 정상) |
| 16×13.5m (216㎡) | 현재 무대 규격 |

### 0-4. 무대 FBX 연결 (건물이 안 보일 때)

프로시니엄·아레나 건물은 v3 `files/stage` 파일이 필요합니다.

```powershell
$v3Stage = "E:\SynologyDrive\StageBuilder_v2_new\StageBuilder_v3\files\stage"
New-Item -ItemType Junction -Path "StageBuilder_v4\server\files\stage" -Target $v3Stage -Force
```

서버를 켠 뒤 페이지를 **새로고침**합니다.

[그림: 프로시니엄 건물 FBX가 로드된 뷰포트]

### 0-5. API 주소 변경 (배포·다른 PC)

기본은 `editor/js/config/app-config.js`의 로컬 주소입니다.  
배포 시 HTML에서 다음을 설정할 수 있습니다.

```html
<script>
  window.__STAGEBUILDER_API__ = 'http://your-server:3000';
</script>
```

## §1 무대 선택·크기·뷰 (Phase 1)

### 1-1. 무대 타입

1. 왼쪽 레일에서 **극장 마스크** 아이콘을 눌러 **무대** 패널을 엽니다.
2. **무대** 드롭다운에서 선택합니다.

| 타입 | 설명 |
|------|------|
| 프로시니엄 | 액자형 무대·건물 셸 (`background.fbx`) |
| 아레나 | 개방형 무대 (`arena_stage.fbx`) |

전환해도 **바닥 크기·중심(원점)** 은 같은 StageProfile을 씁니다. 배경(건물)만 바뀝니다.

[그림: 무대 패널 — 프로시니엄/아레나 선택]

### 1-2. 규격 프리셋 (국내 대공연장 기준)

**규격** 드롭다운에서 고르면 W/D가 바로 적용됩니다.

| 프리셋 | 가로 W | 깊이 D | 비고 |
|--------|--------|--------|------|
| 대공연장 (표준) | 16m | 13.5m | **기본값** · 약 216㎡ |
| 세종예술의전당 대공연장 | 16m | 12m | 프로시니엄 폭·높이 참고 |
| 국립중앙박물관 극장 (용) | 15m | 14.5m | |
| 청양문화예술회관 대공연장 | 16m | 13.5m | |
| 예술의전당 오페라극장 | 20m | 22.5m | 대형(450㎡) · v3 FBX 풀 스케일 |

일반 대공연장 평균은 대략 **가로 15~20m · 깊이 10~14.5m** 입니다.  
오페라 주무대(450㎡)는 그보다 큰 편이라 **프리셋으로만** 두고, 기본은 표준 대공연장으로 맞춰 두었습니다.

[그림: 규격 프리셋 목록]

### 1-3. 직접 크기 입력

1. **W (m)** · **D (m)** 에 숫자를 넣습니다.
2. **크기 적용**을 누릅니다.
3. 한도를 넘기면 자동으로 보정되며, 패널·상태바에 안내가 나옵니다.

**?** 버튼을 누르면 한도·프리셋 설명이 뜹니다.

| | 가로 W | 깊이 D |
|---|--------|--------|
| 조절 가능 범위 (대략) | 15~20m | 10~23m |
| 참고 | 프로시니엄은 건물 FBX 폭 때문에 **가로를 20m 넘게** 키우기 어렵습니다 |

건물·바닥은 W×D로 스케일하되 **건물 높이(Y)는 FBX 원본을 유지**합니다. 사람 표기는 170cm이며, **1m 그리드 대비 약 40% 크기**로 배치해 16×13.5m(216㎡)에 100~200명 안무·합창 밀집이 가능하게 합니다.

[그림: W/D 입력과 크기 적용 · 한도 안내]

### 1-4. 카메라 시점

하단 플로팅 툴바 또는 **보기 → 카메라**에서 고릅니다.

| 버튼 | 시점 |
|------|------|
| P | 원근 |
| AUD | 객석 |
| F | 정면 |
| R / L | 우측 / 좌측 |
| T | 상단 |

마우스 드래그로 궤도 회전, 휠로 줌도 가능합니다.  
툴바의 **확대 / 축소**는 시선 방향으로 조금 이동하는 방식입니다.

**무대 전체 보기:** 하단 툴바의 전체 보기 버튼, **보기 → 무대 전체 보기**, 또는 뷰포트 **더블클릭**.  
패널·메뉴·툴바가 숨겨지고 무대만 창 전체에 표시됩니다. **ESC** 또는 다시 **더블클릭**으로 종료합니다.

[그림: 하단 툴바 카메라 아이콘]

[그림: 객석(AUD) 시점과 정면(F) 시점 비교]

[그림: 무대 전체 보기 모드]

### 1-5. 그리드 (바닥 격자)

오른쪽 메뉴바 끝:

- **그리드** 체크: 표시 On/Off  
- **격자: 자동** (기본): 카메라 거리에 맞춰 칸 간격이 바뀜  
- **격자: 1m 고정**: 굵은 칸이 항상 1m  
- **격자: GridHelper**: Three.js 기본 GridHelper (객체에 가려지는 격자)

**자동·1m 고정**은 v3처럼 바닥 **오버레이** 격자입니다. **GridHelper**는 Three.js 기본 격자로, 사람·소품 **앞 선은 가려집니다**.

또는 **보기 → 도우미**에서 동일하게 설정할 수 있습니다.  
**가이드 도우미**는 무대 중심의 X(빨강)·Z(파랑) 축을 보여 줍니다.

격자(자동·1m)는 바닥과 **깊이 싸움(z-fighting)** 이 나지 않도록, 씬 렌더 **이후** 바닥 높이에 오버레이로 그립니다.

[그림: 그리드 ON · 격자 자동이 선택된 메뉴바 우측]

### 1-6. 자주 하는 확인

1. 프로시니엄 ↔ 아레나 전환 → 바닥 크기·중심이 같은지  
2. 규격을 청양/세종 등으로 바꿈 → 상태바 m·㎡ 갱신  
3. AUD / F / T 시점 전환  
4. 그리드 **자동 ↔ 1m 고정 ↔ GridHelper** 전환  

문제 없으면 **Phase 1 무대** 작업은 여기까지입니다. 다음은 **§2 타임라인**입니다.

## §2 타임라인·키 공통 (Phase 2)

하단 **타임라인**에서 모든 트랙이 같은 규칙으로 키를 다룹니다. (모션·조명은 Phase 3~4에서 트랙이 추가됩니다. 지금은 Demo 트랙으로 연습합니다.)

[그림: 에디터 하단 타임라인 — 룰러·플레이헤드·키 다이아몬드]

### 2-1. 재생·플레이헤드

1. ▶ 재생 / ⏸ 일시정지 (또는 Space)
2. **룰러·빨간 플레이헤드·트랙 빈 곳**을 드래그 → 플레이헤드 스크럽 (따라감)
3. ⏮ / ⏭ 으로 시작·끝으로 이동

> **참고:** 지금은 Demo 트랙만 있어서, 스크럽해도 **무대 3D 애니메이션은 아직 없습니다.**  
> 플레이헤드 ↔ 모션/조명 연동은 **Phase 3~** 입니다.

### 2-2. 키 추가·이동·삭제

1. 왼쪽 트랙 이름을 클릭해 트랙 선택
2. **+ Key** 또는 **K** → 선택 트랙의 **플레이헤드** 위치에 키 추가
3. 다이아몬드 키를 **클릭**하면 해당 모션이 무대에서 선택되고, 플레이헤드가 그 키 시각으로 이동합니다.  
   드래그 또는 **← / →** / **M**으로 시간 이동.  
4. 키 선택 후 **Del** / Delete로 삭제  
5. **우클릭** (키·빈 트랙·트랙 이름):
   - 키 추가 (플레이헤드) / 여기에 키 추가
   - 키 삭제 · 플레이헤드 이동

[그림: 키 선택·드래그·우클릭]

| 단축키 | 동작 |
|--------|------|
| **K** | 선택 트랙 · 플레이헤드에 키 추가 |
| **D** / **Del** | 선택 키 삭제 |
| **← / →** | 선택 키 1프레임 이동 |
| **[ / ]** | 선택 키 1프레임 이동 (대체) |
| **Shift+← / →** | 선택 키 1초 이동 |
| **Alt+← / →** | 선택 키 0.1초 이동 |
| **M** | 선택 키프레임 → 초 입력 이동 |
| **Shift+M** | 플레이헤드 → 초 입력 이동 |
| **Ctrl+Z / Y** | Undo / Redo |
| **Alt+T** | Demo 트랙 추가 |

타임라인 툴바 **?** 버튼으로도 단축키 목록을 볼 수 있습니다.  
(+ Track / 트랙 우클릭으로도 Demo 트랙 추가 가능. 모션·조명 실트랙은 Phase 3~)

### 2-2b. 트랙 (기본)

- 트랙 이름 **우클릭**: 키 추가 / Demo 트랙 추가 / 트랙 삭제
- 모션·조명용 **실트랙**(FBX·Fixture)은 Phase 3~4에서 붙습니다.

### 2-3. Undo / Redo

- 타임라인 **Undo / Redo** 버튼
- 메뉴 **편집 → 실행 취소 / 다시 실행** (Ctrl+Z / Ctrl+Y)

한 번 드래그는 Undo 한 번으로 되돌아갑니다.

### 2-4. 타임라인 길이 (Duration)

기본 길이는 **180초**입니다. Length 칸에서 바꿉니다.

| Duration mode | 의미 |
|---------------|------|
| **Scale keys** | 키 시간을 비율로 늘리거나 줄임 (상대 위치 유지) |
| **Keep absolute / clamp** | 절대 초 유지. 새 끝보다 뒤 키는 제거·클램프 |

예: 180→300 (Scale) 후 2초 키는 약 3.33초에, 300→180 (Keep absolute) 이면 180초 이후 키는 사라집니다.

[그림: Length + Duration mode]

### 2-5. 줌·높이

- − / + 로 가로 줌. (패닝은 타임라인 가로 스크롤)
- 타임라인 **윗변**을 위·아래로 드래그하면 패널 높이가 바뀝니다. (다음에도 기억됨)

### 2-6. 무대 전체 보기와의 관계

**무대 전체 보기**(더블클릭) 중에는 타임라인이 숨겨집니다. ESC로 돌아오면 다시 보입니다.

### §2 확인

1. + Key → Del → Undo로 복구  
2. 키 드래그 후 Undo 한 번  
3. Length 180→300 (Scale keys) 후 키 상대 위치  
4. Keep absolute로 줄일 때 끝 이후 키 clamp  

다음은 **§3 모션**입니다.

## §3 모션·등장/퇴장 (Phase 3)

**v3 정렬:** 객체 1개 = **타임라인 트랙 1줄**(색상 스와치). 클립 리사이즈 없음.  
보였다/안 보였다 = Opacity / Visible. **Undo/Redo**로 키·트랜스폼 복구.

[그림: 속성 패널 + 기즈모 + Assets Motion/Video/Audio]

### 3-1. 모션 추가 (Assets)

1. 왼쪽 **Assets → Motion** (탭: Motion / Video / Audio)
2. **WalkLite (경량)** 샘플 또는 서버 FBX · 업로드(⬆) / 삭제(🗑)  
   (색은 Properties **틴트 색상**)
3. **+** → 무대 배치 + Motion 트랙 1줄(색) · **키 170cm**(현재 무대 m 환산) · WalkLite는 팔다리 워킹

### 3-2. 선택 · 기즈모 · 속성

1. 스테이지에서 객체 **클릭** → 하단 툴 **이동/회전** 기즈모 (사람 모션은 스케일·크기 UI 없음 · 그룹과 통일)
2. 오른쪽 **Properties** 탭
   - **속성** — 위치·회전·틴트·Opacity · 무대 픽 · 빠른 퇴장 · (키 선택 시) 시간/Easing  
   - **구간** — 그룹과 같은 **이동/대기/퇴장** (포메이션 없음) · **구간 적용**으로 키프레임 생성  
3. 타임라인 **키 선택** → **속성** 탭에서 시간 / Easing · **K**/+Key는 같은 시각에 키가 있으면 추가하지 않고 기존 키 선택  
   기즈모·슬라이더 → **선택 키** · Undo  
4. 트랙 헤드: **눈 / ◆키 / 잠금** · 트랙 삭제 시 **스테이지 객체도 제거**
5. 스테이지 객체가 카메라 각도에 따라 사라지면 — **새로고침 후 재배치**  
   (원인: opacity=1인데 transparent 강제 → 깊이 정렬 깨짐 · 수정됨)

**단일 모션 구간 작업 예**
1. 모션 선택 → Properties **구간** 탭  
2. 시작 위치(무대 픽) · +이동/+대기/+퇴장 · Duration  
3. **구간 적용 (키프레임)** → 플레이헤드로 확인  
4. 필요 시 **속성** 탭·타임라인 키로 미세 조정

### 3-3. 그룹 (오른쪽 Ensemble)

1. **+ 그룹 만들기** → 탭 옆 **색상 픽커**로 그룹 틴트 (GO·배치된 멤버에 반영)
2. FBX **리스트** 선택 → **선택 → 그룹에 등록**
3. 시작 카드: From X/Z · **Opacity**(GO 시 멤버 키에 반영 · 퇴장 끝은 0)
4. **+ 이동 / 대기 / 퇴장** — Duration · 끝 X/Z · **무대 클릭** · 포메이션 · Y회전 · Easing
5. **그룹 GO** → 스테이지 배치 + 타임라인 폴더 + **구간 키프레임 적용**  
   (속성·그룹 패널: 하단 드래그로 **높이 조절**)

확인: 플레이헤드를 움직이면 멤버가 구간을 따라 이동하는지.

Assets **업로드/삭제**는 목록만 갱신합니다 (에디터·무대 상태 유지).
