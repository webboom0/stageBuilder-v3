## 오른쪽 패널

| 구역 | 패널 | 역할 |
|------|------|------|
| **프로젝트** | **위치 프리셋** | 무대 공통 좌표 · ⓘ · 칩 → 미리보기 + 트랙/그룹 시작 위치 |
| **프로젝트** | **패턴 라이브러리** | 동작 패턴 보관함 · 어느 씬 트랙에나 적용 |
| **씬** | **Properties** | 선택 트랙 — **속성** / **패턴** 탭 |
| **씬** | **그룹** | Characters 묶음 · 포메이션 · 키프레임 적용 (씬마다 별도) |
| **씬** | **조명** | HOUSE/Fixture 라이브 · + 키 (씬마다 별도) |

Properties **패턴** = 선택 **한 트랙**(씬). **패턴 라이브러리** = **여러 패턴**(프로젝트).

## 타임라인 — Characters / Stage

| 항목 | 내용 |
|------|------|
| **트랙 추가** | Assets **+** · 같은 이름 반복 시 **2, 3…** 자동 번호 |
| **트랙 이름** | 선택 · **F2** · 우클릭 → 이름 변경… · Properties **이름** · Undo 가능 |
| **트랙 삭제** | 선택 · **Del**(확인, 키 미선택) · 우클릭 → 트랙 삭제 |
| **키** | K · D/Del(키) · 드래그 · 우클릭 → **패턴 라이브러리에 저장**(키 2+) |
| **Properties** | **속성** · **패턴** — 퇴장은 패턴·그룹·라이브러리에서 |

| Characters | Stage |
|------------|-------|
| X/Z(Y고정) · Y회전 · 틴트 · Opacity | XYZ · 회전 · 크기 · 색 · Opacity |
| 패턴 — 포메이션 없음 | 패턴 — 동일 UI |

## 타임라인 · Undo/Redo

- **Undo/Redo**: 타임라인 툴바 · 편집 메뉴 · **Ctrl+Z / Ctrl+Y**
- **대상**: 키 추가·삭제·이동 · 트랙 삭제 · **트랙 이름 변경** · 기즈모(키 기록 시) · 조명 키·슬라이더
- **비대상**: 그룹 등록 · 패턴/프리셋 **목록 편집** — 단, **키프레임 적용** 후 생성된 키는 Undo 가능
