## 무대

- 타입: 프로시니엄 / 아레나 (바닥·중심 유지, 배경만 변경)
- 규격 프리셋 또는 W×D(m) 직접 입력 후 크기 적용
- 카메라: P / AUD / F / R / L / T · 무대 전체 보기(더블클릭·Esc)
- 그리드: On · 자동 · 1m · GridHelper

---

## 타임라인

- 초 단위 · 재생/스크럽 · +Key / K · Del · M / Shift+M · Ctrl+Z/Y
- Length · Scale keys / Keep absolute
- 키 클릭 → 무대 선택·플레이헤드

---

## 모션

### 추가
- Assets Motion/Video/Audio · + 로 배치 · 1객체=1트랙 · 키 ~170cm

### 속성 / 구간
- **속성**: 위치 X/Z (Y 고정) · 회전 · 틴트 · Opacity · 무대 픽 · 선택 키
- **구간**: 이동/대기/**퇴장** → 구간 적용 · Linear/Smooth  
  (퇴장은 구간 탭에서만)

### 그룹
- 색 · 등록 · 포메이션 · GO

### 모션 JSON 가져오기
- 파일 → 가져오기 → v3 모션 JSON… (선택 모션 키 덮어쓰기)
