## 무대

- 타입: 프로시니엄 / 아레나 (바닥·중심 유지, 배경만 변경)
- 규격 프리셋 또는 W×D(m) 직접 입력 후 크기 적용
- 카메라: P / AUD / F / R / L / T · 무대 전체 보기(더블클릭·Esc)
- 그리드: On · 자동 · 1m · GridHelper

---

## 타임라인

- 상단 **All · Characters · Stage · Light · Audio** 필터
- 초 단위 · 재생/스크럽 · +Key / K · Del · M / Shift+M · Ctrl+Z/Y
- **길이** — 키 시각 유지(줄이면 범위 밖만 정리) · 트랙은 Assets **+**
- **?** = 타임라인 단축키 (전체 튜토리얼은 도움말 메뉴)
- 키 클릭 → 무대 선택·플레이헤드

---

## 모션

### Characters
- Assets **Characters** / Video / Audio · FBX · + 로 배치 · 1객체=1트랙(Characters 섹션) · 키 ~170cm · 위치 X/Z
- **Video**: + 스크린 재생 · 재생 중 **−** 제거 (🗑 는 파일 삭제)

### Stage
- Assets **Stage** · **직육면체·원통** · FBX/OBJ · + 로 배치 · 속성: 위치·회전·크기·색상·Opacity

### 속성 / 구간
- **속성 — Characters**: X/Z (Y 고정) · Y 회전 · 틴트 · Opacity · 무대 픽 · 선택 키
- **속성 — Stage**: 위치·회전·크기 X/Y/Z · 색상 · Opacity · 무대 픽 · 선택 키
- **구간** (Characters): 이동/대기/**퇴장** → 구간 적용 · Linear/Smooth  
  (퇴장은 구간 탭에서만)

### 그룹
- 색 · 등록 · 포메이션 · GO

### 모션 JSON 가져오기
- 파일 → 가져오기 → v3 모션 JSON… (선택 모션 키 덮어쓰기)

## HOUSE 조명

- 시작 시 **WORK ON** + 슬라이더 · **HOUSE / Fixture** 탭
- HOUSE: Fill · FOH — 라이브 · **+ 키 / ◀▶ / 삭제 / 트랙 삭제**
- 같은 시간 **+ 키** → 덮어쓰기 · 트랙 삭제 시 스테이지 조명 복원
- **Ctrl+Z / Ctrl+Y** (조명 패널·타임라인 공통 스택)

## Fixture 조명

- Fixture 탭: 시트 · **GROUPS**(트랙 없어도 전체 선택) · **Shift/Ctrl** 다중 선택
- Dimmer/Position/Beam/Color · **+ 키** (기존 키는 속성 갱신) · **트랙 삭제**
- 패널 ↔ 타임라인 트랙·키 다중 선택 · Fixture Bus = 화면 전체 밝기만
