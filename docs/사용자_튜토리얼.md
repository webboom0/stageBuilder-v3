> 메뉴 구조: **Assets → 트랙 → 속성** (Characters는 +구간·그룹)

---

## 목차 구조

### Assets
- 공통 · Characters · Stage · **Video** · **Audio**

| 탭 | + 동작 | 타임라인 |
|----|--------|----------|
| Characters | 씬·타임라인 추가 | Characters 트랙 |
| Stage | 씬·타임라인 추가 | Stage 트랙 |
| Video | 배경 재생 · 재생 중 − 제거 | 없음 |
| Audio | 클릭마다 새 트랙 + 클립 | Audio 트랙·클립 |

### Characters
| 항목 | 내용 |
|------|------|
| **트랙** | Assets + → Characters 섹션 · 👁◆🔒 · K/Del/드래그/M · 우클릭 삭제 |
| **속성** | X/Z(Y고정) · Y회전칩 · 틴트 · Opacity · 선택키 Easing — **퇴장 없음** |
| **구간** | +이동·대기·퇴장 · 구간 적용 |
| **그룹** | 등록 · 포메이션 · GO |

### Stage
| 항목 | 내용 |
|------|------|
| **트랙** | Assets + → Stage 섹션 · 키 조작 동일 |
| **속성** | XYZ 위치·회전·크기 · 색 · Opacity — **구간 없음** |

### Light · 조명
| 항목 | 내용 |
|------|------|
| **트랙** | +키 온디맨드 · HOUSE/Fixture · 덮어쓰기 · 트랙 삭제 |
| **속성** | WORK · HOUSE Dim/색/Size · Fixture Pan/Tilt/Zoom/Focus |

### Audio
| 항목 | 내용 |
|------|------|
| **Assets** | Audio 탭 (업로드 · + → 새 트랙·클립) |
| **트랙·클립** | Master/Split/Delete · trim · S 분할 · 재생 동기 |

---

## 타임라인 공통

- All/Characters/Stage/Light/Audio · Space · 길이 180s · Ctrl+Z/Y
