# StageBuilder — 사용자 튜토리얼 (보고서용 요약)

| 항목 | 내용 |
|------|------|
| **진본** | [`editor/tutorial/index.html`](../editor/tutorial/index.html) |
| 갱신 | 2026-08-30 |

> 메뉴 구조: **Assets → 트랙 → 속성** (Characters는 +구간·그룹)  
> 상단 메뉴: **파일 · 편집 · 씬 · 라이브러리 · 보기 · 도움말 · 그리드**  
> **전체 메뉴 표** — HTML [`#menubar`](../editor/tutorial/index.html#menubar) (다른 절의 «파일 → …»는 여기로 연결)

---

## 상단 메뉴 (요약)

| 메뉴 | 주요 항목 |
|------|-----------|
| **파일** | 새 · 열기… · 저장(Ctrl+S) · 스냅샷 · ZIP · 내보내기(프로젝트 ZIP · 현재/전체 렌더) |
| **편집** | 실행 취소/다시(Ctrl+Z/Y) — 키·클립 삭제는 <strong>타임라인</strong> |
| **씬** | 추가·복제·삭제 · 이름… · **이전/다음 Ctrl+[ / ]** · 씬 목록… |
| **라이브러리** | 캐릭터·스테이지·오디오·비디오… — 공용 files 업로드·삭제 (Assets **Lib**는 복사만) |
| **보기** | 도우미(그리드·가이드·골격) · 카메라 · 멀티뷰 · 무대 전체 · F11 |
| **도움말** | 사용자 튜토리얼… · 작업 단위 테스트…(QA) · v4 정보 |
| **그리드(줄)** | 격자 On/Off · 종류 · 멀티뷰 체크 |

## 프로젝트 · 씬 (막)

| 항목 | 내용 |
|------|------|
| **허브** | 새 프로젝트 · 목록 열기 · ZIP 가져오기 · 새로고침 |
| **파일 (편집 중)** | 저장 (Ctrl+S) · 열기·새 프로젝트는 **파일** 메뉴 |
| **로딩** | 허브 진입 · **열기/새/ZIP/씬 전환/무대 타입·규격 변경** — 전체 화면 스피너 |
| **프로젝트 전환** | Assets · 그룹 · Properties · 조명 등 패널 자동 갱신 (이전 공연 목록 잔류 없음) |
| **요약** | 패널 **하단** — 공연명 · 한 줄 요약 · **수정** |
| **정보 항목** | 공연명(필수) · 장르 · 공연기간 · 공연장소/규모 · 연출 |
| **패널** | **상단** 씬 목록 · **저장 안 됨** 배지 · **하단** 공연 요약 · 저장 · + · ↑↓ |
| **씬** | 클릭 전환 · ↑↓ 순서 · **Ctrl+[ / ]** · 더블클릭 이름 · 복제/삭제 |
| **저장** | Ctrl+S · 패널 저장 · **45초** 자동 저장 |
| **스냅샷** | 저장: 파일 → 스냅샷 저장… · 복원: 파일 → 스냅샷에서 복원… |
| **ZIP** | 내보내기 → 프로젝트 ZIP · ZIP 가져오기 → **새 프로젝트** |
| **로드 경고** | 누락 **캐릭터**·오디오·영상 — **업로드·라이브러리**(공용에 있으면 강조) · **씬 다시 불러오기** · 닫기 시 확인(타임라인만 남고 3D 미표시 안내) |
| **프로젝트 편집 (메뉴)** | 파일 → 프로젝트 편집… — **목록**에서 수정·삭제 (패널 수정과 별도) |
| **메뉴 … 표기** | 창·목록·파일 선택 등 **추가 단계** 필요 시 (저장·씬 추가 등 즉시 실행 항목에는 없음) |

## 목차 구조

### Assets (프로젝트 단위)
- 공통 · Characters · Stage · **Video** · **Audio**

| 탭 | + 동작 | 타임라인 |
|----|--------|----------|
| Characters | 씬·타임라인 추가 | Characters 트랙 |
| Stage | 씬·타임라인 추가 | Stage 트랙 |
| Video | 배경 재생 · 재생 중 − 제거 | 없음 |
| Audio | 클릭마다 새 트랙 + 클립 | Audio 트랙·클립 |

### Characters
| 항목 | 내용 |
|------|------|
| **트랙** | Assets + → Characters 섹션 · 눈·◆·잠금(트랙 헤더) · K/Del/드래그/M · 우클릭 삭제 |
| **속성** | X/Z(Y고정) · Y회전칩 · 틴트 · Opacity · 선택키 Easing — **퇴장 없음** |
| **구간** | +이동·대기·퇴장 · 구간 적용 |
| **그룹** | 등록 · 포메이션 · GO |

### Stage
| 항목 | 내용 |
|------|------|
| **트랙** | Assets + → Stage 섹션 · 키 조작 동일 |
| **속성** | XYZ 위치·회전·크기 · 색 · Opacity — **구간 없음** · **바닥 아래 이동 불가** |

### Light · 조명
| 항목 | 내용 |
|------|------|
| **트랙** | +키 온디맨드 · HOUSE/Fixture · 덮어쓰기 · 트랙 삭제 |
| **속성** | WORK · HOUSE Dim/색/Size · Fixture Pan/Tilt/Zoom/Focus |

### Audio
| 항목 | 내용 |
|------|------|
| **Assets** | Audio 탭 (업로드 · + → 새 트랙·클립) |
| **트랙·클립** | Master/Split/Delete · trim · S 분할 · 재생 동기 |

## 타임라인 공통

- All/Characters/Stage/Light/Audio · Space · 길이 180s · Ctrl+Z/Y
- **섹션별 선택 분리** — Characters / Stage / Light / Audio 키·트랙이 섹션 간 동시 하이라이트되지 않음
- **K / ◆** — 마지막 키 추가·선택 트랙 우선 · 섹션 필터(Characters/Stage 등) 켜면 해당 섹션 우선
- **무대 빈 클릭** — 3D 선택만 해제 · 타임라인 키 작업 트랙 유지 (Characters 키 → Stage 이동 → K 연속 작업)
- 프로젝트 재열기 후 새 트랙 추가 — 기존 트랙·키 ID 충돌 방지

## 무대 · 카메라

- **타입** — 프로시니엄/아레나 **썸네일 카드** · **변경** 팝업(프리셋·직접 입력·저장)
- 타입·규격 변경 시 **로딩** · 뷰포트 툴바 · 빌딩고정 · **구조물 투명**
- 같은 W×D면 캐릭터·소품·격자 1m 동일 · 기본 소품은 **Assets Stage**

## 멀티뷰 · 렌더

### 멀티뷰 모니터 (2×2 전체 화면)

- **열기**: 보기 → 멀티뷰 · 뷰포트 우측 체크 · 하단 툴바 2×2 아이콘
- **로딩**: «멀티뷰 준비 중…» 후 네 칸 표시
- **칸 구성**
  - 왼쪽 위: **정면/관객** (드롭다운) — 자동 투명 없음
  - 오른쪽 위: **좌/우** (드롭다운) — 측면 벽 숨김 · 천장·조명바 투명
  - 왼쪽 아래: **상단** — 천장·조명바 자동 투명
  - 오른쪽 아래: **자유** — 드래그·우클릭·휠 · 닫으면 메인에 반영
- **줌**: 칸별 +/− · 해당 칸 위 **마우스 휠**
- **재생**: 팝업 하단 ▶/⏸/⏮ · **Space** (타임라인 동기) · **Esc** 닫기

### 구조물 투명 (하단 툴바)

- **투명 ↔ 불투명** 토글 (기본 불투명)
- **메인** · 멀티뷰 **정면/관객·자유** 칸에 적용
- 대상: **건물·무대 셸** — **조명·빔·캐릭터·소품 제외**
- 멀티뷰 **상단·좌/우**는 시점별 자동 처리 (툴바와 별도)

### 렌더

- **렌더 스튜디오** 팝업: 미리보기 · 카메라 설정 → 렌더 시작 (1280×720 WebM, **오디오 포함**)
- **전체 렌더** — 씬 순서대로 **WebM 1개** (`프로젝트명_all_scenes.webm`)
- 렌더 중 **에디터 작업 차단** · 그리드·가이드는 출력에 미포함
