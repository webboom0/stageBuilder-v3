## 상단 메뉴 (요약)

| 메뉴 | 주요 항목 |
|------|-----------|
| **파일** | 새 · 열기… · 저장(Ctrl+S) · 스냅샷 · ZIP · 내보내기(프로젝트 ZIP · 현재/전체 렌더) |
| **편집** | 실행 취소/다시(Ctrl+Z/Y) — **타임라인·기즈모·조명 키** (프리셋·패턴 목록 편집은 제외) |
| **씬** | 추가·복제·삭제 · 이름… · **이전/다음 Ctrl+[ / ]** · 씬 목록… |
| **라이브러리** | 캐릭터·스테이지·오디오·비디오… — 공용 files 업로드·삭제 (Assets **Lib**는 복사만) |
| **보기** | 도우미(그리드·가이드·골격) · 카메라 · 멀티뷰 · 무대 전체 · F11 |
| **도움말** | 사용자 튜토리얼… · 작업 단위 테스트…(QA) · v4 정보 |
| **그리드(줄)** | 격자 On/Off · 종류 · 멀티뷰 체크 |

## 화면 구성 (요약)

| 영역 | 패널 |
|------|------|
| **왼쪽** | 프로젝트 · 무대 · Assets |
| **오른쪽** | **위치 프리셋** · Properties · **그룹** · **패턴 라이브러리** · 조명 |
| **하단** | 타임라인 (Undo/Redo · Ctrl+Z/Y) |

---

## 위치 프리셋 · 패턴 라이브러리

| 패널 | 역할 |
|------|------|
| **위치 프리셋** | 프로젝트 공통 무대 좌표(등장·퇴장 등) · 칩 클릭 → 미리보기 + 선택 트랙/활성 그룹 시작 위치 적용 · 타이틀 **ⓘ** 설명 |
| **패턴 라이브러리** | 이동→대기→퇴장 **동작 패턴** 저장 · 선택 트랙에 **키프레임 적용** · 트랙 **우클릭 → 패턴 라이브러리에 저장**(키 2개+) |

Properties **패턴** 탭 = 선택 **한 트랙** 편집. 패턴 라이브러리 = **여러 패턴 보관함**.

| **툴바** | **왼쪽 개수** · **오른쪽** 새로고침 · Lib · 업로드 · 삭제 |

## Characters

| 항목 | 내용 |
|------|------|
| **트랙** | Assets + · K/Del/드래그 · **우클릭 → 패턴 라이브러리에 저장** · 우클릭 삭제 |
| **속성** | X/Z(Y고정) · Y회전 · 틴트 · Opacity — **퇴장 없음** |
| **패턴** | +이동·대기·퇴장 · **키프레임 적용** · 위치 프리셋 칩 |
| **그룹** | 등록(드래그) · 포메이션 · **트랙 없음 → 트랙 추가 및 키프레임 적용** / **있음 → 키프레임 적용** |

| **패턴** | Character와 동일 UI · **키프레임 적용** |

## 타임라인 · Undo/Redo

- **Undo/Redo**: 타임라인 툴바 · 편집 메뉴 · **Ctrl+Z / Ctrl+Y**
- **대상**: 키 추가·삭제·이동 · 트랙 삭제 · 기즈모(키 기록 시) · 조명 키·슬라이더
- **비대상**: 그룹 등록 · 패턴/프리셋 **목록 편집** — 단, **키프레임 적용** 후 생성된 키는 Undo 가능
