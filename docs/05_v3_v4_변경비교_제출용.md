## 1. 요약

StageBuilder v4는 v3의 기능을 단순 이식한 업데이트가 아니라, **타임라인·키프레임·프로젝트·무대**를 공통 모델로 재설계한 **전면 재구축**입니다.

| 구분 | v3 | v4 |
|------|----|----|
| 코드 구조 | 대형 단일 파일·전역 의존 | ES module · `domain/` · `ui/` 분리 |
| 타임라인 | 트랙 종류마다 키 UX 상이 | `TimelineEngine` 단일 키 모델 |
| 등장·퇴장 | 클립 길이 조절에 의존 | `opacity` / `visible` 키 + **패턴** 탭 |
| 프로젝트 | ZIP 중심·단일 씬 | **폴더형 프로젝트** · **멀티 씬(막)** |
| 무대 | 스케일·중심 불일치 | `StageProfile` (대공연장 16×13.5m 표준) |
| 조명 | 레거시 select 조명 + HOUSE/Fixture 혼재 | **HOUSE·Fixture만** · 단일 엔진 |
| 사용자 안내 | MD 위주 | **HTML 튜토리얼** 진본 + MD 동기화 |

**한 줄 요약:** v4는 「같은 연출 도구」를 **통일된 키프레임·씬·프로젝트 구조**로 다시 만든 버전이며, v3 대비 **패턴·프리셋·AI 초안·멀티씬·오디오 클립 편집** 등 실사용 워크플로가 크게 개선되었습니다.

## 2. 재구축 배경

### 2.1 v3에서 확인된 한계

1. **키프레임 모델 불통일** — 모션·조명·오브젝트마다 키 추가·이동·편집 방식이 달랐음.
2. **등장/퇴장 개념 혼선** — 모션 클립 길이를 줄이면 캐릭터만 사라지는 등, 조명·오디오와 다른 규칙.
3. **조명 이중 저장** — `TimelineData`와 `lightTracks` JSON이 공존하여 저장·로드·UI 버그 유발.
4. **단일 씬·ZIP 중심** — 1막·2막 분리·서버 폴더형 프로젝트 목록이 어려움.
5. **무대 스케일 불일치** — 프로시니엄/아레나 전환 시 바닥·그리드·객체 기준점 불일치.
6. **코드 유지보수** — 타임라인·에디터 파일 수천 줄 단일 파일, 전역 변수 의존.

### 2.2 v4 설계 원칙

- 모든 트랙: **절대 초(seconds)** 키 · 동일 Command(추가·삭제·이동·편집·Undo).
- 등장/퇴장: **클립 리사이즈 금지** → opacity/visible 키 + 패턴(이동·대기·퇴장) 설계.
- 저장: **프로젝트 폴더**(`project.json` + `scenes/`) 1차 · ZIP 보내기·스냅샷.
- 배포: pivot `server.js` 라우트 호환 + `API_BASE_URL` 단일 설정.

## 5. 사용자 UI·워크플로 변경 (실무 관점)

### 5.1 v3 사용자가 v4에서 달라지는 점

1. **등장·퇴장** — 클립 끝을 줄이지 않고, Properties **패턴** 탭에서 이동·대기·퇴장을 설계한 뒤 **키프레임 적용**합니다.
2. **씬 작업** — 왼쪽 **프로젝트** 패널에서 막(씬)을 추가·전환합니다. 씬마다 타임라인·그룹·조명이 따로 저장됩니다.
3. **공통 좌표** — **위치 프리셋**(등장·중앙·퇴장 등)을 프로젝트 전체에서 쓰고, 패턴·그룹·AI `@`에 연결할 수 있습니다.
4. **패턴 재사용** — 잘 만든 동작은 **패턴 라이브러리**에 저장하거나, 트랙 우클릭으로 가져올 수 있습니다.
5. **조명** — 예전 select 방식 조명 트랙은 없습니다. HOUSE/Fixture 채널을 **조명 패널**에서 고르고 **+ 키**로 기록합니다.
6. **오디오** — 클립 핸들 trim · **S** split으로 v2 수준 편집이 가능합니다.

### 5.2 오른쪽 패널 구성 (v4)

| 패널 | 저장 범위 | 역할 |
|------|-----------|------|
| Properties | 씬 | 선택 트랙 — **패턴**(기본) / **속성** |
| 그룹 | 씬 | Characters 묶음 · 포메이션 · 키프레임 적용 |
| 패턴 라이브러리 | 프로젝트 | 동작 패턴 보관·적용 |
| 위치 프리셋 | 프로젝트 | 무대 공통 좌표 |
| 조명 | 씬 | HOUSE/Fixture 라이브 · + 키 |

### 5.3 AI 패턴 (v4 신규)

| 구분 | 예시 | 의미 |
|------|------|------|
| Duration | `1분 대기` | 그 구간 길이(60초) |
| 절대 시각 | `1분까지 대기` | 타임라인 1:00까지 대기 |

| 기본값 | ⏱ 버튼 | 시간 생략 시 이동·대기·퇴장 각 기본 초 |
