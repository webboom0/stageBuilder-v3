## 3. 핵심 데이터 모델

### 3.1 Project

```typescript
// 개념 스키마 (JS 구현)
Project {
  id: string
  name: string
  version: 4
  stageProfile: StageProfile
  scenes: Scene[]
  activeSceneId: string
  createdAt, updatedAt
}

Scene {
  id: string
  name: string           // "1막", "2막"
  order: number
  durationSec: number
  stageType: 'proscenium' | 'arena'
  timeline: {
    motion: MotionTimelineData
    light: LightTimelineData
    audio: AudioTimelineData
  }
  showControl: ShowControlData
  sceneGraph: SerializedObject[]  // Three.js refs
}
```

### 3.2 StageProfile

```javascript
{
  name: 'Grand Hall (default)',
  widthM: 16,
  depthM: 13.5,
  heightM: 9.5,        // 프로시니엄 높이 참고
  origin: 'center',    // 바닥 중앙 = (0,0,0)
  humanHeightM: 1.7,
  unit: 'meter'        // 1 Three unit = 1m
}
```

변경 시: `StageManager.applyProfile()` → 그리드, fixture fit, 카메라 bounds 재계산.

### 3.3 통일 Track / Keyframe

```javascript
Track {
  id: string              // e.g. "obj:{uuid}:opacity"
  kind: 'scalar' | 'vec3' | 'color' | 'bool'
  keyframes: [{ timeSec, value, easing }]
}

Clip {
  id, trackId, startSec, durationSec
  // visibility 제어 없음 — opacity/visible Track 사용
}
```

**가상 트랙 (조명 HOUSE/Fixture):** 한 시각에 여러 property → UI diamond 1개, 편집 패널에서 prop 탭.

### 3.4 시간 축 규칙

| 항목 | 규칙 |
|------|------|
| 저장 | **절대 초** (`timeSec`) |
| UI X 위치 | `timeSec / durationSec * 100%` |
| Duration 변경 | 사용자 선택: **Scale keys** 또는 **Keep absolute** (초과 클립 clamp) |
| FPS | 스냅·표시용; 저장은 초 단위 float |

## 4. Visibility / Exit 통일

| v3 | v4 |
|----|-----|
| 클립 width 줄임 → 사라짐 | **금지** (클립은 구간만) |
| `visible` track + clip 밖 hide | `visible` 또는 `opacity` track |
| `endsWithExit` on sprite | exit **키** 또는 preset "Add exit fade" |
| 조명 dim 0 | 동일 키 모델 |

모든 SceneObject(캐릭터, 소품, 무대 prop)는 optional tracks:

- `visible` (bool)
- `opacity` (0~1)

## 6. 서버·클라이언트 설정

**`editor/js/config/app-config.js`:**

```javascript
export const API_BASE_URL =
  (typeof window !== 'undefined' && window.__STAGEBUILDER_API__)
  || import.meta.env?.VITE_API_BASE_URL
  || (location.hostname === 'localhost' ? 'http://localhost:3000' : '');
```

모든 upload/list fetch는 `API_BASE_URL + '/api/...'`.

로컬 server는 pivot `server.js`의 StageBuilder 섹션과 **동일 경로**:

- `STAGEBUILDER_FILES_ROOT`
- `/api/upload-audio`, `/api/fbx-files`, …
- `/files` static
- dev: `requireAuth` bypass 옵션 (`DEV_SKIP_AUTH=1`)
