타임라인 — 재생 · 키프레임

하단 타임라인에서 시간을 맞추고 키를 편집합니다. 시간은 초 단위입니다.

  • 상단 All · Characters · Stage · Light · Audio 로 트랙 섹션을 필터합니다
  • ▶ / Space — 재생 · 일시정지
  • 룰러·빨간 플레이헤드를 드래그하면 시간을 스크럽합니다
  • 트랙을 고른 뒤 + Key 또는 K — 현재 시간에 키 추가
  • 키를 클릭하면 무대에서 해당 모션이 선택되고, 플레이헤드가 그 시각으로 이동합니다
  • Del — 키 삭제 · Ctrl+Z / Ctrl+Y — 실행 취소 · 다시 실행
  • M — 선택 키를 초 단위로 이동 · Shift+M — 플레이헤드 이동
타임라인 · 플레이헤드 · 키

타임라인 길이 · 실행 취소

기본 길이는 180초입니다. 툴바 길이에서 바꿉니다.

길이를 바꿔도 키 시각은 그대로 둡니다. 길이를 줄이면 새 끝보다 뒤에 있는 키만 정리됩니다.

트랙은 타임라인에서 만들지 않습니다. Assets에서 Characters / Stage를 + 로 올리면 트랙이 생깁니다.

타임라인 윗변을 위·아래로 드래그하면 패널 높이가 바뀌며, 다음에도 기억됩니다.

? 버튼은 사용자 튜토리얼이 아니라 타임라인 단축키 안내입니다. 전체 튜토리얼은 메뉴 도움말에서 엽니다.

Characters 추가 · Assets

  1. 왼쪽 Assets에서 Characters / Stage / Video / Audio 탭을 고릅니다.
  2. Characters·Stage는 기본 항목 또는 업로드 파일에서 + 로 올립니다. Video는 + 재생 · 재생 중 − 제거합니다.
  3. Characters 하나당 타임라인 Characters 섹션에 트랙 한 줄이 생깁니다.
Characters는 무대 기준 키 약 170cm로 맞춰 배치됩니다. 위치는 X/Z만 조절합니다(Y 고정). 보였다/안 보였다는 클립 길이가 아니라 Opacity와 구간 탭의 퇴장으로 조절합니다. 업로드 시 탭별 허용 형식·용량이 아니면 경고창이 뜹니다.
Assets · Characters 배치

Stage 추가

  1. Assets에서 Stage 탭을 고릅니다.
  2. 목록의 직육면체 · 원통(기본) 또는 FBX/OBJ에서 + 로 배치합니다.
  3. Stage는 타임라인 Stage 섹션에 트랙으로 추가됩니다.
Stage는 사람 키 스케일을 쓰지 않습니다. Properties 속성에서 위치 · 회전 · 크기 · 색상 · Opacity를 조절할 수 있습니다. Opacity 0으로 키를 두면 무대 밖·퇴장 연출에 쓸 수 있습니다. 그룹(앙상블)에는 Characters만 등록할 수 있습니다.
Assets · Stage 배치

속성 · 구간

모션을 선택하면 오른쪽 Properties가 열립니다.

  • 속성 — Characters — 위치 X/Z (Y 고정) · Y 회전 칩 · 틴트 · Opacity · 무대에서 위치 지정 · (키 선택 시) 시간·Easing
  • 속성 — Stage — 위치 X/Y/Z · 회전 X/Y/Z · 크기 X/Y/Z · 색상 · Opacity · 무대에서 위치 지정 · (키 선택 시) 시간·Easing
  • 구간 (Characters만) — 이동 · 대기 · 퇴장 흐름을 만든 뒤 구간 적용으로 키프레임 생성

구간으로 움직이기 · 퇴장

  1. 모션 선택 → 구간 탭
  2. 시작 위치(무대 클릭) · +이동 / +대기 / +퇴장 · 시간(Duration)
  3. 구간 적용 (키프레임) 후 플레이헤드로 확인
  4. 필요하면 속성 탭이나 타임라인에서 다듬기
퇴장은 구간 탭에서만 만듭니다. (+퇴장 → 위치·시간 설정 → 구간 적용)

Easing: Linear는 등속, Smooth는 부드러운 가속·감속입니다. 새 이동/퇴장 구간은 바로 앞 구간의 Easing을 이어받습니다.

그룹

  1. + 그룹 만들기 → 탭 옆 색으로 그룹 틴트
  2. Assets Characters 목록에서 FBX를 골라 그룹에 등록
  3. 시작 위치 · Opacity · 이동/대기/퇴장 · 포메이션 · 간격
  4. 그룹 GO — 무대에 배치하고 타임라인에 구간 키를 적용

플레이헤드를 움직이며 멤버가 함께 움직이는지 확인합니다.

모션 JSON 가져오기

이전 버전에서보낸 모션 키 JSON을 현재 모션에 덮어쓸 수 있습니다.

  1. 무대 또는 타임라인에서 대상 모션을 선택
  2. 파일 → 가져오기 → v3 모션 JSON…
  3. JSON 파일을 고릅니다. 트랙이 여러 개면 번호를 입력합니다.
선택해 둔 모션의 기존 키는 가져온 내용으로 바뀝니다. 실행 취소로 되돌릴 수 있습니다.

HOUSE 조명

무대 기본 조명(Fill · FOH 좌/중/우)은 오른쪽 레일 조명 패널에서 조절합니다. 타임라인 Light 트랙은 필요할 때만 추가합니다.

시작 시 WORK가 켜져 있습니다. 옆 슬라이더로 작업등 밝기를 조절합니다. 그 아래 HOUSE / Fixture 탭에서 작업할 조명을 고릅니다.

  1. 오른쪽 조명 패널(전구 아이콘)을 엽니다.
  2. HOUSE 탭에서 Fill · FOH L/C/R을 선택합니다.
  3. Dim · 색상 · Size는 라이브로 바뀝니다. 탭 안의 + 키 · ◀▶ · 삭제 · 트랙 삭제로 기록·정리합니다.
  4. 같은 시간에 다시 + 키하면 새 키가 겹치지 않고 덮어씁니다.
  5. 트랙 삭제: 패널 트랙 삭제 또는 타임라인 Light 라벨 우클릭 → 트랙 삭제 — 스테이지 조명도 함께 꺼집니다.
조명 슬라이더·WORK·+키·트랙 삭제는 실행 취소(Ctrl+Z)로 되돌릴 수 있습니다. 새 키는 Smooth 전환으로 저장됩니다.

Fixture 조명

머리 위 18대는 Fixture 탭에서 고릅니다. 처음부터 트랙이 생기지 않습니다.

키프레임: 선택 → 라이브 → Fixture 탭의 + 키 · ◀ ▶ · 삭제.

  1. 번호(11~36) 클릭 · Shift/Ctrl로 다중 선택 · GROUPS(G1~G6, All/Odd/Even)은 트랙 없어도 전체 선택
  2. Dimmer / Position / Beam / Color로 조절 · + 키로 기록 (이미 키 있으면 속성만 갱신)
  3. ◀ ▶ · 휴지통 · 트랙 삭제 · 타임라인 키 드래그/Delete · 라벨 우클릭 삭제
  4. 전체 밝기(Fixture Bus) 슬라이더는 키 값은 유지한 채 화면만 밝기 조절
타일 ·T / 초록 = 트랙 있음 · 없으면 회색(선택 후 +키로 트랙 자동 생성). 패널·타임라인 조명 작업은 Ctrl+Z / Ctrl+Y 지원.
