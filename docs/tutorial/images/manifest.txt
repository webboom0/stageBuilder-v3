캡처 시 참고 (최신 UX)
- 패널 타이틀 뱃지: 「프로젝트」(공통·씬 전환 시 유지) / 「씬」(씬 전환 시 갱신)
- ⓘ 도움말: 접힌 패널에서도 화면 위에 표시 (fixed)
- 트랙 이름: F2 · 우클릭 → 이름 변경… · Properties 이름 · Undo
- 같은 Assets 이름 여러 번 + → WalkLite 2, 3…
- 트랙 삭제: Del(확인) · 우클릭 → 트랙 삭제
- Properties 패턴 ≠ 패턴 라이브러리 (씬 1트랙 vs 프로젝트 보관함)

팁
- Win+Shift+S → 영역 캡처 후 PNG로 저장
- 패널만 필요하면 해당 영역만 잘라도 됨 (HTML은 가로 100%로 맞춤)
- 캡처 후 튜토리얼 새로고침 → 「그림 없음」 점선이 사라지면 성공
- 24~26은 신규 — 없으면 HTML에 점선 placeholder 표시 (정상)
