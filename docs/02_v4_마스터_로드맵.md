## 용량·ZIP 정책 (Phase 6 설계)

| 모드 | 내용 | 용도 |
|------|------|------|
| **Project folder (기본)** | JSON + `/files/music/`, `/files/fbx/` **상대 경로** | 일상 편집, 서버 배포 |
| **Export ZIP (link)** | JSON만 + manifest of external paths | 가벼운 공유 |
| **Export ZIP (bundle)** | JSON + 사용된 fbx/wav 복사 | 오프라인·다른 PC |
| **Limit** | bundle 시 500MB 경고, 1GB 상한 협의 | UI progress |

서버 `files/projects/{id}/` 예:

```
project.json
scenes/scene_01.json
scenes/scene_02.json
manifest.json
```
