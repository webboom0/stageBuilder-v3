## 4. v3에서 v4로 이전하는 교훈 (이미 반영된 설계)

| v3 문제 | v4 설계 대응 |
|---------|----------------|
| 클립 width = visibility | opacity/visible track only |
| v3 레거시 LIGHTING (`light_*` + select) | v4 미지원 · import 제외 |
| lightTracks 이중 저장 | 단일 TimelineEngine |
| ZIP only, blob in audio | folder primary + export zip |
| 무대 스케일 불일치 | StageProfile |
| API config 분산 | API_BASE_URL |
| 6000+ line timeline files | domain modules |

### 6.4 Phase 3 — 모션 (진행)

#### 문제점
- v3: 클립 width = visibility, endsWithExit 이중 규칙
- 초안: 속성마다 6트랙 + 스케일 1.7 world unit → 무대에서 안 보임
- 단일 vs 그룹 UX 불일치 · Properties에 객체/스크립트 탭 혼선
- 구간 From/끝 X 입력에 무대 픽 소수 자릿수가 넘쳐 패널 밖으로 깨짐
- Assets 업로드 시 IDE 파일 감시로 에디터 전체 리로드 위험

#### 수정 내용 (v3 정렬 · 안정화)
- **1 객체 = 1 트랙** + 트랙 색 · compound 키 (pos/rot/scale/opacity/visible)
- 스폰: 건물 FBX Y 유지 · W×D · **HUMAN_STAGE_SCALE≈0.24** · 간격 ~0.7m · 카메라=덱 중심
- Properties 탭 **속성 / 구간** (스크립트 제거)
  - **속성**: 위치·Y회전 칩·틴트·Opacity·무대 픽·선택 키
  - **구간**: 이동/대기/퇴장 (포메이션 없음) · **구간 적용** → 그룹 GO와 동일 키 파이프라인 (퇴장은 구간만)
- 그룹 Ensemble: 색상 픽커 · Opacity · 이동/대기/퇴장 · 포메이션 · GO
- 그룹·단일 구간 폼: **좌표 소수점 2자리** + CSS `minmax(0,1fr)`로 입력칸 오버플로 방지
- Assets 업로드/삭제: **목록만 갱신** · `server/files/**` `.cursorignore`
- 키 동일 시각 중복 금지 · 드래그 겹침 방지 · 보임/안보임 UI 제거(퇴장·opacity)
- 트랙 삭제 → 스테이지 메시 제거 · Skinned FBX frustum cull 비활성
- 타임라인: 키 클릭→무대 선택·스크럽 · M / Shift+M · 스크롤바 슬림
- **Smooth 보간 복구**: v3처럼 `smoothstep` ease-in/out, `Linear`와 실제 차이 적용
- **퇴장**: 속성 탭 제거 · **구간** 탭(+퇴장)만 사용
- **v3 motion JSON import**: `파일 → 가져오기 → v3 모션 JSON…` · 선택 트랙 키 덮어쓰기
- **사용 안내 진본**: `editor/tutorial/` · `/stageBuilder/tutorial/` · MD 동기화
- Characters / **Stage** 분리 · Stage 기본 메시(직육면체·원통) · 속성 XYZ
- **Video 배경**: Assets **+** 재생 · 재생 중 **−** 제거 · 스크린 가림벽 숨김
- 타임라인 툴바: Duration mode / + Track 제거 · **길이**=키 시각 유지 · **?**=단축키

#### 관련 파일

### 6.8 UX·안정화 (2026-08-28)

#### 문제점
- 상태 표시줄이 하단 툴바에 가려짐
- 객석 시점이 너무 가깝거나 멀게 보임
- 기즈모 드래그 시 플레이헤드에 키 없어도 키가 생기거나 위치가 남음
- 첫 키 전에도 Stage/Character가 보임
- 타임라인 키 선택과 무대 선택 불일치
- Stage 기본 메시(박스·원통) 크기 과대
- 네이티브 title 툴팁 가독성·패널 overflow 잘림

#### 수정 내용
- **상태 표시줄** → 상단 메뉴 바로 아래 (`#status`)
- **빌딩고정** 툴바 — 궤도 pan/rotate 끔 · 한글 툴팁·상태 메시지
- **객석(AUD) 프레이밍** — 무대 전체가 보이도록 blend 조정
- **기즈모 규칙** — 플레이헤드 키 또는 선택 키만 기록 · 없으면 `motion.apply()`로 복귀
- **첫 키 이전** — `sampleMotionBag` visible=false · opacity=0
- **선택 동기** — 타임라인 키 ↔ 무대 · `syncStageFromTimelineSelection`
- **Stage 기본 메시** — 직육면체 0.5m · 원통 R0.25m H0.5m
- **한글 floating 툴팁** — `initTooltips.js` · `#sb-tooltip-float` (패널 clip 방지)

#### 관련 파일
- `ViewportToolbar.js` · `ViewportInteraction.js` · `CameraPresets.js`
- `sampleTracks.js` · `stageMeshPrimitives.js` · `bootstrap.js`
- `initTooltips.js` · `tooltips.css` · `editor-shell.css`
