StageBuilder 에디터

무대·모션·타임라인으로 공연 연출을 구성하는 에디터입니다. 왼쪽 메뉴는 Assets → 트랙 → 속성 순으로 연결됩니다. 에디터에서는 도움말 → 사용자 튜토리얼… 로 이 안내를 엽니다.

프로젝트 · 씬 (막)

에디터를 열면 먼저 프로젝트 허브에서 공연을 고르거나 새로 만듭니다. 편집 중에는 왼쪽 프로젝트 패널(필름 아이콘)에서 공연명과 씬 목록을 확인합니다.

스냅샷 (작업 되돌리기)

지금 연 프로젝트 폴더가 서버에 있을 때, 씬·타임라인·조명 설계만 백업하고 나중에 되돌릴 때 씁니다. 음악·FBX 등 에셋은 프로젝트 폴더에 그대로 두고 JSON만 저장·복원합니다.

메뉴동작
파일 → 스냅샷 저장…현재 프로젝트 JSON을 ZIP으로 다운로드 (_snapshot_날짜.zip)
파일 → 스냅샷에서 복원…저장해 둔 스냅샷 ZIP을 지금 연 프로젝트에 덮어쓰기 (확인 후)
스냅샷 복원은 프로젝트를 연 상태에서만 사용하세요. 허브 「ZIP 가져오기」와는 다릅니다.

프로젝트 ZIP (다른 PC · 새 공연)

에셋까지 포함해 통째로 옮기거나 새 프로젝트로 열 때 사용합니다.

메뉴포함 내용용도
내보내기 → 프로젝트 ZIP (에셋 포함)…씬 JSON + FBX·음악·영상 등 전체백업 · 다른 PC
ZIP 가져오기 (에셋 포함)…허브 · 파일 메뉴 — 새 프로젝트로 가져오기다른 PC에서 받은 ZIP

씬 로드 경고

씬을 열 때 모션·오디오·영상·에셋 파일을 찾지 못하면 경고 창이 뜹니다. 스냅샷 복원 후에는 에셋이 그대로 있으면 보통 뜨지 않습니다.

에디터 진입·씬 전환 시 무대·건물·씬 로드가 끝날 때까지 로딩 화면이 표시됩니다.
씬마다 타임라인·모션·조명이 따로 저장됩니다. Assets는 프로젝트마다 묶입니다.

타임라인 — 공통

하단 타임라인에서 시간을 맞추고, 섹션별 트랙·키·클립을 편집합니다. 시간은 초 단위입니다.

재생 · 스크럽

  • 상단 All · Characters · Stage · Light · Audio — 섹션 필터
  • ▶ / Space — 재생 · 일시정지
  • 룰러·빨간 플레이헤드 드래그 — 시간 스크럽
  • 타임라인 윗변 드래그 — 패널 높이 (다음에도 기억)
  • ? — 타임라인 단축키 (전체 튜토리얼은 메뉴 도움말)

길이 · 실행 취소

  • 기본 180초 · 툴바 길이에서 변경
  • 길이를 줄여도 키 시각은 유지 — 새 끝보다 뒤 키만 정리
  • Ctrl+Z / Ctrl+Y — 실행 취소 · 다시 실행

선택 · 키 추가 (K)

  • Characters · Stage · Light · Audio — 섹션마다 선택이 분리됩니다. 다른 섹션 키가 동시에 노란색으로 표시되지 않습니다.
  • 키 다이아몬드 클릭 — 해당 트랙·키 선택 · 무대 객체 선택 · 플레이헤드 이동
  • K / ◆ — 마지막으로 키를 추가·선택한 트랙에 플레이헤드 키 추가 (상단 Characters / Stage 등 필터가 켜져 있으면 그 섹션 우선)
  • 트랙 라벨 클릭 — 그 트랙을 키 추가 대상으로 지정
  • 무대 빈 곳 클릭 — 3D 선택만 해제 · 타임라인 선택·키 작업 트랙은 유지
예: Characters에 키 추가 → Stage 소품을 기즈모로 이동 → 플레이헤드만 옮긴 뒤 K — 방금 작업하던 Characters 트랙에 키가 추가됩니다. Stage 트랙에서 키를 직접 추가·선택하면 그때부터 K 대상이 Stage로 바뀝니다.
트랙 추가 방법은 종류마다 다릅니다 — 아래 Characters / Stage / Light / Audio 각 「트랙」 항목을 참고하세요.

Assets — 공통

왼쪽 레일 Assets에서 Characters·Stage·Video·Audio 파일을 관리합니다. 탭·툴바·업로드 규칙은 모든 탭에 공통입니다.

탭별 + 동작·배치 방법은 아래 Characters · Stage · Video · Audio 항목을 참고하세요.

탭업로드 형식+ 버튼타임라인

Characters

타임라인 Characters 섹션 — WalkLite·FBX 등 사람 모션. 1객체=1트랙, compound 키(위치·회전·Opacity 등).

흐름 Assets + → 트랙 → Properties 속성 · 구간 · 그룹 패널

  • 트랙 — 추가 · 키 · 삭제 · 이동 · 잠금
  • 속성 — X/Z · Y회전 · 틴트 · Opacity (퇴장 없음)
  • 구간 — 이동 · 대기 · 퇴장 · 구간 적용

Characters — 트랙

흐름 Assets Characters + → 타임라인 Characters 트랙 → 속성 · 구간 · 그룹

트랙 추가

  1. Assets → Characters에서 WalkLite 또는 FBX +
  2. 1 객체 = 타임라인 Characters 섹션 트랙 1줄
  3. 현재 플레이헤드에 첫 키 생성 · 첫 키 이전은 비표시

동작방법
키 추가트랙 선택 → ◆ 또는 K · 같은 시각 키 있으면 선택만
키 선택다이아몬드 클릭 → 무대 객체 선택 · 플레이헤드 이동
키 삭제키 선택 → Del / D
키 이동키 드래그 · ←/→ 1프레임 · Shift 1초 · Alt 0.1초 · M 초 입력
키 수정키 선택 → 속성 또는 기즈모 (플레이헤드 키 또는 선택 키 필요)

모션 JSON 가져오기

이전 버전에서보낸 모션 키 JSON을 현재 모션에 덮어쓸 수 있습니다.

  1. 무대 또는 타임라인에서 대상 모션을 선택
  2. 파일 → 가져오기 → v3 모션 JSON…
  3. JSON 파일을 고릅니다. 트랙이 여러 개면 번호를 입력합니다.
선택해 둔 모션의 기존 키는 가져온 내용으로 바뀝니다. 실행 취소로 되돌릴 수 있습니다.
