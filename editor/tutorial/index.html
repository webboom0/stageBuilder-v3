StageBuilder 에디터

무대·모션·타임라인으로 공연 연출을 구성하는 에디터입니다. 왼쪽 메뉴는 Assets → 타임라인 → 오른쪽 패널 순으로 연결됩니다. 에디터에서는 도움말 → 사용자 튜토리얼… 로 이 안내를 엽니다.

프로젝트 · 씬 (막)

에디터를 열면 먼저 프로젝트 허브에서 공연을 고르거나 새로 만듭니다. 편집 중에는 왼쪽 프로젝트 패널(필름 아이콘)에서 공연명과 씬 목록을 확인합니다.

스냅샷 (작업 되돌리기)

지금 연 프로젝트 폴더가 서버에 있을 때, 씬·타임라인·조명 설계만 백업하고 나중에 되돌릴 때 씁니다. 음악·FBX 등 에셋은 프로젝트 폴더에 그대로 두고 JSON만 저장·복원합니다. 메뉴: 파일 → 스냅샷 저장… / 스냅샷에서 복원… (저장 시 _snapshot_날짜.zip 다운로드).

스냅샷 복원은 프로젝트를 연 상태에서만 사용하세요. 허브 「ZIP 가져오기」와는 다릅니다.

프로젝트 ZIP (다른 PC · 새 공연)

에셋까지 포함해 통째로 옮기거나 새 프로젝트로 열 때 사용합니다. 파일 → 내보내기 → 프로젝트 ZIP (에셋 포함)… · 파일 → ZIP 가져오기 (에셋 포함)… · 허브 ZIP 가져오기.

씬 로드 경고

씬·프로젝트를 열 때 캐릭터·오디오·영상 등 프로젝트 에셋 파일을 찾지 못하면 경고 창이 뜹니다. 씬 JSON과 타임라인 트랙은 열리지만, 무대(3D)에는 해당 객체가 나타나지 않을 수 있습니다.

항목설명
누락 종류캐릭터 · 오디오 · 비디오 · 에셋 (파일명 표시)
업로드PC에서 파일을 프로젝트에 올림 (해당 Assets 탭으로 자동 전환)
라이브러리공용 라이브러리에서 프로젝트로 가져오기 — 공용 files에 있으면 버튼이 강조되고 «공용 라이브러리에 있음» 안내 표시
씬 다시 불러오기파일 추가 후 — 3D·재생에 반영
닫기경고만 닫고 편집 계속 · «파일 없이 계속할까요?» 확인 후 진행 가능
타임라인 트랙·클립은 그대로 남습니다. 파일을 넣지 않고 닫으면 트랙만 보이고 무대에는 비어 있을 수 있습니다. 나중에 Assets 탭에서 추가한 뒤 씬 다시 불러오기 또는 씬 전환으로 복원하세요.
씬마다 타임라인·모션·조명이 따로 저장됩니다. Assets는 프로젝트마다 묶입니다.

무대 타입 · 규격

  1. 왼쪽에서 무대 패널을 엽니다.
  2. 상단 썸네일 카드에서 타입(프로시니엄 / 아레나)을 고릅니다.
  3. 아래 규격 이름 옆 변경으로 프리셋·직접 입력을 고릅니다.
타입설명
프로시니엄액자형 무대 · 건물 배경 (카드 썸네일 참고)
아레나개방형 · 원형 무대 느낌 (카드 썸네일 참고)

타입·규격을 바꿀 때 전체 화면 로딩이 표시됩니다. 타입을 바꿔도 바닥 크기와 중심은 그대로이고 배경(건물)만 바뀝니다.

같은 W×D 규격이면 프로시니엄·아레나 모두 캐릭터·소품·격자 1m 크기가 동일합니다.

길이 · 실행 취소 · 다시 실행

  • 기본 180초 · 툴바 길이에서 변경
  • 길이를 줄여도 키 시각은 유지 — 새 끝보다 뒤 키만 정리
  • 타임라인 툴바 Undo · Redo 또는 Ctrl+Z / Ctrl+Y (메뉴 편집과 동일)

Undo/Redo 대상 — 타임라인 키 추가·삭제·이동 · 트랙 삭제 · Character/Stage 트랙 이름 변경 · 기즈모 드래그(키가 기록될 때) · 조명 키·패널 슬라이더. Characters/Stage 등장 클립 길이도 마지막 키와 함께 Undo/Redo됩니다.

Undo 대상 아님 — 그룹 멤버 등록 · 구간/패턴 설계만 저장 · 위치 프리셋·패턴 라이브러리 목록 편집(프로젝트 JSON). 다만 키프레임 적용으로 타임라인에 키가 생긴 뒤에는 그 키 편집은 Undo 가능.

선택 · 키 추가 (K)

  • Characters · Stage · Light · Audio — 섹션마다 선택이 분리됩니다. 다른 섹션 키가 동시에 노란색으로 표시되지 않습니다.
  • 키 다이아몬드 클릭 — 해당 트랙·키 선택 · 무대 객체 선택 · 플레이헤드 이동
  • K / / 툴바 + Key — 키 작업 대상 트랙에 플레이헤드 키 추가 (아래 우선순위)
  • 툴바 ◀ ▶ — 대상 트랙에서 이전/다음 키 선택 · 플레이헤드 이동 (, / .)
  • 트랙 라벨 클릭 — 그 트랙을 키 작업 대상으로 지정
  • Character/Stage 트랙 선택 · F2 — 트랙 이름 변경 · Del — 트랙 삭제(확인, 키 미선택 시)
  • Characters·Stage — 타임라인 툴바 Clip / Keys 로 등장 클립 막대 표시 전환 (등장 클립)
  • 무대 빈 곳 클릭 — 3D 선택만 해제 · 타임라인 선택·키 작업 트랙은 유지
키 작업 대상 트랙 (선택이 없어도 K · + Key · ◀ ▶에 사용): (1) 상단 Characters / Stage 등 섹션 필터가 켜져 있으면 그 섹션의 최근 키 작업 트랙 → 없으면 그 섹션 첫 트랙 → (2) 전체에서 가장 최근 키·트랙 선택 → (3) 현재 선택 트랙 → (4) 없으면 첫 Characters 트랙.
예: Characters에 키 추가 → Stage 소품을 기즈모로 이동 → 플레이헤드만 옮긴 뒤 K — 방금 작업하던 Characters 트랙에 키가 추가됩니다. Stage 트랙에서 키를 직접 추가·선택하면 그때부터 대상이 Stage로 바뀝니다.
트랙 추가 방법은 종류마다 다릅니다 — 아래 Characters / Stage / Light / Audio 각 「트랙」 항목을 참고하세요.

구조물 투명 (하단 툴바)

구조물 투명 버튼은 메인 뷰포트와 멀티뷰의 정면/관객 · 자유 칸에 적용됩니다. 클릭할 때마다 투명 ↔ 불투명이 전환됩니다 (기본 불투명).

  • 대상: 건물·무대 셸 (FBX 배경)
  • 조명 기구·빔·캐릭터·소품은 투명 처리하지 않음
  • 멀티뷰 상단 · 좌/우 칸은 시점에 맞게 자동 처리 (툴바 토글과 별도)
칸 사이 구분선은 굵게 표시됩니다. 멀티뷰가 열려 있으면 파일 → 내보내기 → 현재 씬 렌더… / 전체 렌더… 시 팝업이 잠시 닫힌 뒤 녹화됩니다.

렌더 (WebM)

렌더 스튜디오 팝업에서 카메라·미리보기를 확인한 뒤 녹화합니다. 렌더 중에는 에디터 작업이 차단됩니다.

내보내기

  • 파일 → 내보내기 → 현재 씬 렌더… — 활성 씬 1개
  • 파일 → 내보내기 → 전체 렌더… — 프로젝트 씬을 순서대로 이어 WebM 1개

렌더 스튜디오

  1. 팝업 미리보기에서 카메라(객석·정면·좌·우·상단·원근·현재 시점) 선택
  2. 렌더 시작 — 팝업 안에서 진행률·미리보기 확인 (에디터 조작 불가)
  3. 완료 시 .webm 다운로드 · 1280×720
상단·좌/우는 구조물 자동 처리. 타임라인 오디오 클립은 WebM에 함께 녹음됩니다. 렌더 완료·취소 후 플레이헤드·편집 중 씬(전체 렌더)·멀티뷰는 자동으로 되돌아갑니다 (복원 버튼 없음).
